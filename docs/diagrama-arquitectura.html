Decisiones clave de esta arquitectura

El Gateway no valida nadaEs un enrutador puro. Cada microservicio protege sus propias rutas con su propio middleware JWT — así cada uno se puede desplegar y probar por separado.
Una base por servicioComparten el mismo contenedor de Postgres por simplicidad de despliegue, pero cada base es exclusiva de su microservicio: ninguno lee la base de otro directamente.
Sincronización desacopladaCuando algo cambia en un servicio y otro necesita enterarse (stock de equipos, índice de búsqueda), se avisa por HTTP interno sin bloquear la respuesta al usuario si el otro servicio está caído.
